# Data dictionary

Time is hours. D,C,F,B1,B2,L are normalized amount units; the reference volumes are one. q1,q2,km and sensor kd are in the same concentration-equivalent units. ka,kel,kreturn,koff,kint are h^-1. Association kon values are concentration^-1 h^-1; vmax is amount h^-1. A is hours and efficacy dimensionless. Sensor gain and offset are optical units.

model_spec.json defines case identity, parameter order and bounds, calibration bounds, rank cutoff, acceptance tolerances and decision limits. chips.json defines six independent systems. Its known rate constants are exact; standards and observations identify chip-specific sensor responses. There are 120 protocol/time/channel observations per chip, no missing values and no stochastic error beyond decimal rounding. Protocols and courses have pulses as [time,dose] pairs and blockade windows as named start/end/strength/site records. Course costs are resource units independent of simulated amount states. Scenarios multiply named chemical parameters and do not change known constants. No optional patient-level covariates exist.

The input validator checks hashes, identifiers, shapes, event domains, positivity and channel pairing. The data manifest fixes all scientific JSON inputs. output_schema.json defines the answer and run_summary_schema.json the execution record. deliverables.json in the task directory enumerates mandatory pipeline artifacts. SOURCE_RIGHTS.md and source_provenance.json document ownership and generation.
