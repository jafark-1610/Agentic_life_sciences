# Task pipeline

Read `prompt.md` and `data/data_dictionary.md`, then run `data/validate_dataset.py`. Infer each culture's joint feasible flux and calibration set from the immutable JSON inputs. Enumerate the intervention menu, calculate flux ranges and robust utility envelopes, select the design and construct a feasible maximizing witness. Write the structured answer and analysis using the command contract in the prompt.

`requirements.txt` lists the numerical and schema packages used by validation. `data/output_schema.json` defines answer fields. `data/data_manifest.json` fixes the analysis inputs. `data/source_provenance.json` and `data/SOURCE_RIGHTS.md` document the synthetic-data origin and permitted use.
