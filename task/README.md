# Task workflow

Read `prompt.md` and `data/data_dictionary.md`, validate the scientific input, then implement the command in `deliverables.json`. The five required artifacts are pipeline code, dependency declaration, structured answer, diagnostic report and execution summary.

`data/output_schema.json` and `data/run_summary_schema.json` define structured outputs. `data/data_manifest.json` fixes scientific input hashes. Input data, event conventions, parameter units, acceptance criteria and resource costs are entirely supplied with the task.
